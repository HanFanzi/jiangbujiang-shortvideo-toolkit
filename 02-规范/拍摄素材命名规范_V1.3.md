> 适用范围：自有素材（`[项目根]/02_自有素材/`）、成片（`[项目根]/03_成片/`）。目录当前为空，从零建立，无存量包袱。
> 口径来源：用户拍板 2026-11-23（发布后ID回传、二级目录、五段受控词表、素材总清单.csv）、用户拍板 2026-11-24（拍摄地点词表合并）、用户拍板 2026-11-27（拍摄地点改为对标画面场景语义，新增「车内」「办公室」）、DECISIONS D06/D09、SPEC §4 与 §5 链路2、ASSET-006/007/009、V1.8 §八、`短视频全流程自动化方案_源文` §3.1。
> V1.3 相对 V1.2 的变更：拍摄地点段语义由「我方复刻场地」改为「对标画面场景」（车内口播不再命名为展厅），受控词表由四选一扩为六选一（新增「车内」「办公室」）。V1.2 保留不删。

## 结论先行

1. **三类素材分二级目录**：`片头`（门店店长拍）、`产品`（我方拍）、`工厂`（我方拍）；目录 `02_自有素材/片头/`、`产品/`、`工厂/`，分类词同时进文件名，双重冗余。
2. **五段全受控词表**：`{品牌}_{分类}_{景别}_{拍摄地点}_{四位序号}.mp4`。**禁止自由文本**——自由文本会让 AI 检索漏匹配；画面描述写进总清单「画面描述」列，不进文件名。
3. **素材名不带作品ID**：自有素材是可复用镜头库，一条素材可能进多条成片；作品ID/脚本ID的对应关系写在成片 sidecar 的输入清单里。
4. **成片有两个ID**：本地临时内部ID `{作品ID}-RMnn` 只用于混剪落盘和 sidecar 命名；**平台发布后的ID由人工回传**，写表3「🔴成片路径/验收反馈」。`-RMnn` 不能当最终发布ID。
5. **素材总清单.csv 是AI选素材的唯一入口**：AI 读清单 + 脚本分镜要点做匹配，不逐个看视频（§七）。
6. **发布不在我方**：成片交门店自行发布（D06）；发布后由人工回传平台ID（§四、§六）。

## 二、文件命名（五段受控词表）

格式：`{品牌}_{分类}_{景别}_{拍摄地点}_{四位序号}.mp4`

| 段 | 取值（受控词表，不得自造） | 规则 |
|---|---|---|
| 品牌 | [品牌E] / [品牌A] / [品牌C] / [品牌B] / 通用 | 用户原话「通用则写通用」 |
| 分类 | 片头 / 产品 / 工厂 | 与二级目录名一致；三选一 |
| 景别 | 远景 / 全景 / 中景 / 近景 / 特写 | 五选一，按画面景别 |
| 拍摄地点 | 展厅 / 门店 / 五金车间 / 装配线 / 车内 / 办公室 | 六选一；取**对标画面的实际场景**，非我方复刻场地（车内口播写「车内」、办公桌前口播写「办公室」）；产品特写无独立场景时跟所属视频主场。原「摩豆展厅」「[品牌A]展厅」已合并为「展厅」（用户 2026-11-24） |
| 四位序号 | `0001`–`9999` | 按「品牌+分类+景别+地点」四段同值递增；前四段+序号构成唯一键 |

**硬约束**：
- 五段全部取自上表，不接受同义词、简称、错别字（如不能写「摩豆展厅」「[品牌A]展厅」，须写受控词「展厅」；不能写「驾驶室」须写「车内」）。词表外的取值须先由用户确认后增补词表，不得临时造词。
- **拍摄地点段按对标画面场景取值**：从分镜「机位参考」「道具参考」推断——含车内/驾驶座/车座/安全带→车内，含办公桌/办公室→办公室，含五金车间→五金车间，含装配线→装配线，含门店/门头/导购→门店，含展厅/样机或无场景线索的产品特写→展厅。禁止因"我方在展厅复刻"就把车内镜头命名成展厅。
- **画面描述不进文件名**（长文本、自由表述会让匹配失效），写进 `素材总清单.csv` 的「画面描述」列。
- 文件名不含日期、不含作品ID；拍摄日期写总清单。

## 三、序号与多段编号

- 序号在「品牌+分类+景别+地点」四段相同的组内递增：如 `[品牌C]_产品_特写_展厅_0001.mp4`、`[品牌C]_产品_特写_展厅_0002.mp4`。
- 任一四段取值变化即开新组，序号从 `0001` 重起。
- 一条成片可跨品牌、跨分类、跨地点取段；段与段的先后不在文件名里编码，由混剪片段计划（`plan_cuts`）决定；如需固定顺序，在成片 sidecar 的输入清单里按顺序列出文件名。
- 成片总长 15–60 秒（SCRIPT-006；SPEC §5 `plan_cuts`）；素材总时长不足 15 秒即报错，不得出片。

## 四、与作品ID / 脚本ID / 成片ID 的对应

| 标识 | 格式 | 出现在哪 | 来源 |
|---|---|---|---|
| 作品ID | 纯数字串 | 表2 唯一主键；本地临时ID前缀 | FETCH-001 |
| 脚本ID | `{作品ID}-Snn` | 表5「🟢关联作品ID」；表4「🟢关联脚本ID」 | SCRIPT-012 |
| 本地临时内部ID | `{目标作品ID}-RMnn` | 混剪落盘文件名 + sidecar 文件名；仅内部使用 | SPEC §4 `[假设]`，V1.1 降级为临时ID |
| **平台发布后ID** | **平台实际返回的成片ID（人工回传）** | **表3「🔴成片路径/验收反馈」** | **用户拍板 2026-11-23** |
| 素材文件名 | `{品牌}_{分类}_{景别}_{拍摄地点}_{四位序号}.mp4` | `02_自有素材/{分类}/`；sidecar 输入清单；素材总清单 | 本规范 |

```
自有素材（可复用，无作品ID） ─┐
                              ├─> 本地 {作品ID}-RM01.mp4 + sidecar ─> 交门店发布
脚本 {作品ID}-S01（终版文案） ─┘                                      │
                                                                    └─> 人工回传平台发布后ID
                                                                        └─> 表3「🔴成片路径/验收反馈」
```

**`-RMnn` 不是最终发布ID**：它只在本地落盘与 sidecar 命名中使用。成片发布后，由人工回传平台发布后ID并写入表3（§六、反馈规范 §一）。

## 五、拍摄状态怎么标注

拍摄状态是**对标素材的复刻进度**，写在表3（素材索引），不是写在素材文件名里。

| 表3字段 | 枚举 | 联动规则 |
|---|---|---|
| 🟡可拍摄判定 | 可拍 / 有条件可拍 / 不可拍 | 四问：结构可迁移、我方有场景人员、参数可替换、15–60秒成本可控；四项全满足=可拍，缺1项且补齐动作明确=有条件可拍，硬伤=不可拍（ASSET-006） |
| 🔴判定依据 | 文本 | 写四问结果与不可拍原因 |
| 🔴拍摄状态 | 未开始 / 待排期 / 拍摄中 / 已拍待验收 / 返工 / 已完成 | 任一完成条件缺失不得写「已完成」（ASSET-007） |
| 🔴复刻状态 | 未复刻 / 复刻中 / 已复刻 | 拍摄状态进入「拍摄中/已拍待验收/返工/已完成」→ 同步改为「复刻中/已复刻」（ASSET-009） |
| 🔴成片路径/验收反馈 | 见 §六 | 发布后ID回传的落点 |

**表3「已完成」必须全有值**：`路径=...；验收结果=...；验收人=...；验收日期=...`（V1.8 §八）。缺任一项写「已拍待验收」或「返工」。

## 六、成片命名、临时ID与 sidecar

| 阶段 | 文件 | 命名 / 内容 | 谁负责 |
|---|---|---|---|
| 混剪落盘 | 成片 | `{作品ID}-RMnn.mp4`（本地临时内部ID），H.264，含 1 条硬字幕（drawtext 显式 fontfile）、1 处转场 | 我方混剪 |
| 混剪落盘 | sidecar | `{作品ID}-RMnn.内部验证.md`：①「内部验证·不二次分发」字样 ② UTC 生成时间 ③ 输入素材清单（文件名 + 脚本ID） | 我方混剪 |
| 交付门店 | 成片文件 + sidecar | 交门店自行发布（D06） | 我方交付 |
| 发布后回传 | 表3「🔴成片路径/验收反馈」 | 回填**平台发布后ID** + 路径 + 验收结果 + 验收人 + 验收日期 | 人工回传岗 |

sidecar 缺失或内容不全 → 成片不交付（`mark_internal_use` 失败即抛，SPEC §5）。中文字幕必须显式指定字体文件，实测 `fontfile=/System/Library/Fonts/STHeiti Medium.ttc`（SPEC §3）。

成片不进 `01_对标素材/`；对标视频不进成片输入（SPEC §11.1）。

## 七、素材总清单.csv

**一份总清单，AI 读它选素材**；路径 `[项目根]/02_自有素材/素材总清单.csv`。新增、移动、作废素材必须同步更新清单（反馈规范 §一「素材清单维护」节点）。

| 列 | 填什么 |
|---|---|
| 文件名 | 完整文件名（含 `.mp4`），与磁盘一致 |
| 相对路径 | 相对 `[项目根]/02_自有素材/` 的路径，如 `产品/[品牌C]_产品_特写_展厅_0001.mp4` |
| 品牌 | 受控词表值 |
| 分类 | 受控词表值（片头/产品/工厂） |
| 景别 | 受控词表值（远景/全景/中景/近景/特写） |
| 拍摄地点 | 受控词表值（展厅/门店/五金车间/装配线/车内/办公室），与文件名第4段一致 |
| 画面描述 | 一句话说明画面内容；**只写这一列，不进文件名** |
| 适用段落 | 钩子 / 留存 / 价值 / 互动（四段标签） |
| 时长 | 秒，ffprobe 实测 |
| 拍摄日期 | `YYYYMMDD` |
| 可用性 | 可用 / 不可用（作废）/ 待复核 |
| 备注 | 其他需说明项（如画面缺陷、版权限制） |

**示例行**

```csv
文件名,相对路径,品牌,分类,景别,拍摄地点,画面描述,适用段落,时长,拍摄日期,可用性,备注
[品牌C]_产品_特写_展厅_0001.mp4,产品/[品牌C]_产品_特写_展厅_0001.mp4,[品牌C],产品,特写,展厅,[品类]机身不锈钢拉丝特写,价值,6.2,20261123,可用,
通用_片头_中景_门店_0001.mp4,片头/通用_片头_中景_门店_0001.mp4,通用,片头,中景,门店,门店门头与导购迎客中景,钩子,4.8,20261123,可用,
```

**AI 选素材流程**：读 `素材总清单.csv` + 脚本分镜要点 → 按「景别」「分类」「品牌」「画面描述」四列匹配 → 输出候选文件名交给混剪。**不逐个打开视频看**；匹配不到或选错按反馈规范 §一「AI选素材失败」节点写表4素材审核。

## 八、文件名正反例

**正确**

```
[品牌C]_产品_特写_展厅_0001.mp4
通用_片头_中景_门店_0001.mp4
[品牌A]_工厂_全景_五金车间_0002.mp4
```

**错误**

```
20261123_产品_C8max_02.mp4              # V1.0 旧格式，V1.1 停用：品牌/景别/地点段缺失
[品牌C]_产品_机身特写_展厅_0001.mp4      # 景别自造「机身特写」，不在五类受控词表
[品牌C]_产品_特写_[品牌A]展厅_0001.mp4      # 地点「[品牌A]展厅」不在受控词表，须写「展厅」
[品牌A]_产品_近景_驾驶室_0001.mp4            # 地点「驾驶室」不在受控词表，须写「车内」
通用_片头_0001.mp4                      # 缺景别、地点两段
[作品ID]-产品.mp4            # 素材名绑了作品ID：该镜头无法复用于其他成片
```

> 成片正例：本地临时 `[作品ID]-RM01.mp4` + `[作品ID]-RM01.内部验证.md`；发布后平台ID另行人工回传表3，**不用 `-RM01` 充当发布ID**。
