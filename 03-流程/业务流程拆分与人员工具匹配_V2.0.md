# [项目] 业务流程拆分与人员工具匹配 V2.0

## 结论

1. 当前阶段（17:19 用户修正）：不推进具体工作执行，优先跑通「获取对标短视频和账号 → 拆解 → 复刻 → 发布 → 数据回传」全链路，验证工具可用性，对细节调整。下表「阶段」列与工时测算为规划期口径，当前阶段不按此排产。
2. 全链路拆成 31 个动作，分 5 段；A7 为对标视频结构/框架梳理，补上复刻所需的结构参考。
3. 视频生产主线是 1:1 复刻；二创（重组）只在复刻后数据表现好时触发，属后置分支，不是默认路径。
4. 31 个动作全部有明确承接岗。对标选号归投流运营（内部转岗补上），分镜筹备、下载打标归拍摄剪辑。
5. 工具现状：超级编导已购买；其部分功能与现有工具重叠、实际体感不佳，暂标注不切换；A5/A6/A9 执行主体暂定 WorkBuddy。红狐注册后充值积分即可，mcp 平台凭证[已配置]（②）。
6. 成本暂不纳入测算：超级编导已购，其余暂不计。
7. [决策人] 5 项决策：3 项已定（① 投流岗内部转岗、② 平台凭证[已配置]、③ 流程方案已确认可执行），2 项继续挂起（④ 店播错峰时段、⑤ [品牌E]执行方式）。③ 已定不等于启动素材治理，按当前阶段不推进具体执行。
8. 数据反哺覆盖自有账号和门店账号；对标账号只作复刻来源，不进反哺。客服留资数据纳入回流。
