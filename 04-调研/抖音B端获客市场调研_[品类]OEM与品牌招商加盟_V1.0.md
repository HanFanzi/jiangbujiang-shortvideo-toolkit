# 抖音 B 端获客市场调研：[品类] OEM 代工 + 厨电品牌招商加盟 V1.0

**结论：两条业务线必须拆成两个账号、两套内容、两个直播间。** OEM 客户要的是"工厂靠不靠谱"（资质、交期、起订量、品控），加盟客户要的是"开店能不能赚钱"（投入、收益、扶持、安全感）。混在一个账号讲，两边都不信。

四个直接影响内容的事实：

1. **国补退出、新国标落地。** 2026 年烟机、灶具被移出国家补贴，GB 29539-2025、GB 30720-2025 实施，公模贴牌小厂出清，有 OEM 厂商反映 3 月中下旬起接不到订单（S2）。
2. **合规能力成了第一信任点。** 新国标下老机型变库存废铁，"过不过得了新国标"是 OEM 客户和加盟商共同的第一问。
3. **存量焕新替代新房。** 2025 年新建商品房销售面积 -8.7%、住宅销售额 -13.0%（S2），"以旧换新、上门检测、拆旧换新"成为有内容的场景。
4. **29 个省市已落地地方专项补贴**（S2），方向指向高能效、绿色、智能、适老——这是可以反复讲的内容素材。

## 二、B 端用户关注什么

### 2.1 OEM 代工客户（品牌商、电商卖家、渠道商、工程商）

| 关注点 | 他们实际在问 | 内容必须给出的证据 |
|---|---|---|
| 资质合规 | 过没过 3C、ISO9001、新国标 | 证书原件拍摄、检测报告编号、CNAS 实验室 |
| 起订门槛 | 多少台起订、能不能混批试单 | 50 台起订、可混批、试单后放量（S7） |
| 打样交期 | 多久出样、多久交付 | 15 天改模打样、30 天小批量、常规 7—10 天发货（S7） |
| 品控能力 | 有没有实测、出了质量问题谁担 | 老化测试线、气密性检测、油脂分离度 88%、PICC 承保（S4/S7） |
| 产能与排产 | 年产能多少、进度透不透明 | 年产能数据、每 5 天反馈进度照片（S7） |
| 售后配件 | 网点多少、响应多快 | 售后网点数、2 小时响应 48 小时出方案（S7） |
| 定制能力 | 能不能改外观、气源、Logo、包装 | 按电商热销款微调、降低库存风险的案例（S7） |

排序建议：资质 → 品控 → 交期 → 起订量 → 售后。前两项不过关，后面讲得再好也不转化。

### 2.2 品牌招商客户（经销商、加盟商、门店老板）

加盟商决策的 4 个核心问题（S3，厨电抖音招商案例实测）：

| 关注点 | 他们实际在问 | 内容必须给出的证据 |
|---|---|---|
| 投入成本 | 总投入多少、回本周期、风险可不可控 | 逐项拆账、无隐藏收费、不压货政策 |
| 收益确定性 | 正常盈利区间、闭店率、有无真实案例 | 门店实景、加盟商出镜，**不报具体收入数字** |
| 总部扶持 | 选址、运营、流量、培训到不到位 | 引流派单、带教陪跑、短视频脚本、督导驻店（S4/S5/S6） |
| 长期安全感 | 是不是割韭菜、能不能长期做 | 品牌历史、门店总数、发展节奏、创始人出镜 |

厨电行业额外三问：

| 额外关注 | 为什么现在特别在意 | 对应内容 |
|---|---|---|
| 新国标库存风险 | 老机型变废铁，压货即亏损 | "不压货、轻资产试错"政策（S4） |
| 会不会做线上获客 | 县乡门店缺团队缺方法 | 总部统一引流派单、短视频脚本输出（S5/S6） |
| 以旧换新政策 | 县乡高频需求，政府+企业双补贴 | 补贴 35%、旧机抵 300 的活动拆解（S4） |

## 四、视频内容怎么定

### 4.1 OEM 代工线选题

| 选题 | 前 3 秒钩子 | 给的证据 |
|---|---|---|
| 工厂溯源 | "50 台也能做贴牌，带你看看产线" | 车间、产线、检测线实拍 |
| 新国标避坑 | "公模机过不了新国标，仓库货直接变废铁" | GB 29539-2025 解读 + 自家检测报告 |
| 打样全流程 | "15 天出样，30 天小批量，全流程实拍" | 需求→打样→排产→每 5 天进度→质检发货 |
| 参数实测 | "爆炒辣椒，油脂分离度现场测给你看" | 油脂分离度、风量、噪音实测 |
| 资质逐项展示 | "选代工厂就看三样：资质、检测线、售后" | 3C、ISO9001、气密性检测设备 |
| 贴牌案例 | "一个电商品牌从 0 起订到稳定出货，我们做了什么" | 起订量、改模次数、交付周期 |

### 4.2 品牌招商线选题

| 选题 | 前 3 秒钩子 | 给的证据 |
|---|---|---|
| 老板出镜拆成本 | "开一家我们品牌的店到底要花多少钱，一笔一笔算" | 加盟费、设备、首批物料、装修逐项，标注无隐藏收费 |
| 加盟商一天跟拍 | "我去年开的店，今天带你看看一个上午怎么用" | 门店实景、督导带店；**不报具体收入数字** |
| 现场试烟演示 | "爆炒辣椒后拆开烟机，里面长这样" | 实物演示，客户到店率涨 3 倍是腾米经销商案例（S4） |
| 政策一图读懂 | "3 分钟看懂加盟费用和扶持政策" | 费用表、补贴、带教周期 |
| 新国标以旧换新 | "旧烟机抵 300，再享政府补贴，怎么算" | 补贴比例 35%、旧机折抵（S4） |
| 总部引流证据 | "加盟商不用自己拓客，开店就能接单" | 派单截图、抖音本地生活排名（S5） |

### 4.3 两条线共同的三条硬规则

1. 前 3 秒必须抛钩子或冲突，否则完播率起不来。
2. 片尾统一引导留资，用资料包做钩子，不说空泛的"咨询客服"。
3. 加盟线全程挂"投资有风险，加盟需谨慎"角标：入口图、封面、视频画面、落地页四处都要有（S9）。

## 五、直播内容怎么定

### 5.1 直播间场景

| 区域 | OEM 线 | 加盟线 |
|---|---|---|
| 产品展示区 | 全品类样机、核心部件拆解 | 主推套系、爆款单品 |
| 资质展示区 | 3C、ISO、检测报告、专利墙 | 特许经营备案、商标、获奖 |
| 工厂投屏区 | 产线实时监控、检测线画面 | 样板店巡店画面 |
| 答疑区 | 工程单/批发/起订量政策 | 连麦答疑、老加盟商访谈 |

### 5.2 标准流程（一条线一套话术，不混用）

| 环节 | OEM 线内容 | 加盟线内容 |
|---|---|---|
| 开场留人 | 今天讲什么、给什么资料包 | 今天算什么账、有什么政策 |
| 工厂溯源 | 车间、检测线、产线直播 | 总部实力、仓储、培训基地 |
| 产品讲解 | 工艺、参数、新国标达标 | 主推款卖点、以旧换新场景 |
| 案例展示 | 贴牌客户交付案例 | 样板店实景、加盟商连麦 |
| 答疑转化 | 起订量、交期、报价、售后 | 投入、回本、闭店率、扶持 |
| 引导动作 | 留资领报价单/样品申请 | 留资领成本清单/选址工具包 |

此流程与行业 B 端工厂直播岗位的标准动作一致（S10）。

### 5.3 排期

| 阶段 | 动作 |
|---|---|
| 测试期 | [数值] 元试播一场，验证话术和留资（S9） |
| 稳定期 | 每周一场，固定工作日 19:00—21:00（创业者活跃度最高，S8） |

## 七、落地前需要你确认的

以下内容缺一项，对应的内容线就少一个信任点。未确认前不执行开户、投放、发布。

| 待确认 | 为什么必须确认 |
|---|---|
| OEM 与加盟是否同一公司主体；有无特许经营备案（两店一年）、R 标 | 决定加盟线能不能投、会不会被拒审 |
| 工厂实际资质：3C、ISO9001、检测设备、CNAS 实验室、年产能 | OEM 线全部视频的证据来源 |
| 起订量、打样周期、交期、售后网点数 | OEM 线话术的核心参数 |
| 加盟模型：单店总投入、加盟费、闭店率、可合规表述的盈利案例 | 招商线成本拆解内容的数据源 |
| 抖音企业号现状：是否已开、主页装修、历史素材 | 决定冷启动还是改版 |
| 投放预算档位：[数值] 万 / [数值] 万 / [数值] 万每月 | 决定素材量和直播频次 |
| 出镜人：创始人、业务经理、加盟商各是谁 | 信任建立三步法的落点 |
