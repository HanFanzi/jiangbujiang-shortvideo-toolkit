# 抖音取数开源方案：源码审阅

## 结论

两个仓库源码干净，是纯只读实现：只访问 `creator.douyin.com` 本人账号后台，不发布、不改后台、不回传登录态、无遥测、无第三方上报。全仓唯一外发付费域名 `redfox.hk` 出自一个独立脚本，默认只报价不联网、不碰登录态。

落地障碍有三处：🟠 `moonlit-douyin-extractor` 带作者本人专属门槛（环境变量 `MOONLIT_DOUYIN_OWNER=1`）且新版 SKILL.md 把浏览器入口改成依赖私有 `ego-browser`，不是开箱即用的通用工具；🟡 `douyin-data-mcp` 单账号，且会在本机开 9333 调试端口；🟠 两个仓库都直接调创作者后台内部接口，平台改版即失效。

按本轮口径：只下载源码审阅，未安装依赖、未启动浏览器、未运行任何脚本、未改 skill。

## 二、接口清单（源码实测）

`douyin-data-mcp/collect.js`，全部在已登录的 `creator.douyin.com` 页面内用 `fetch(url, {credentials:"include"})` 发同域请求：

| 用途 | 方法 | 路径 |
|---|---|---|
| 登录态探测 | GET | `/web/api/media/user/info/` |
| 作品清单分页 | GET | `/janus/douyin/creator/pc/work_list?status=0&count=50&max_cursor=…` |
| 垂类参数（深度指标必带） | GET | `/janus/douyin/creator/data/item_analysis/involved_vertical` |
| 单条深度指标 | POST | `/janus/douyin/creator/data/item_analysis/item_performance` |
| 账号近 7 天总览 | POST | `/janus/douyin/creator/data/overview/dashboard` |
| 粉丝总览 | GET | `/janus/douyin/creator/data/overview/dashboard/fans?recent_days=7` |

两处 POST 的请求体只有查询参数（`start_date`/`end_date`/`genres`/`primary_verticals`/`metric_type`、`recent_days`），是查询接口，不是写接口。脚本头部边界写明「只读自己账号的数据，不发布、不改后台、不代替登录」，`fetch.mjs`、`launcher.mjs`、`mcp.mjs` 三处重复同一声明。

`moonlit-douyin-extractor` 不自己发请求，用 `page.on('response')` 被动拦截创作者后台页面自身发出的 XHR：

| 用途 | 拦截路径特征 |
|---|---|
| 作品列表 | `/aweme/v1/creator/item/list`、`/creator/pc/work_list`、`/web/aweme/post` |
| 评论列表 | `/aweme/v1/creator/comment/list/`、`/creator/comment/list/`、`/web/api/third_party/aweme/api/comment/read` |
| 评论回复 | `/comment/list/reply/`、`/comment/reply/list/` |
| 登录身份 | `https://creator.douyin.com/aweme/v1/creator/user/info/`、创作者主页资料响应 |

## 三、写操作核查

| 项 | 结果 |
|---|---|
| 发布 / 删除 / 回复 / 举报 / 私信 / 点赞 / 关注 | 全仓 0 处。`comments.mjs:154` 明确注释 `Expand only read controls; never click 回复/发送/删除/举报.` |
| 页面上的 `click` | 仅 3 类只读控件：「选择作品」对话框、`查看N条回复` 展开、对话框关闭；其余为滚动、翻页、`End` 键、鼠标滚轮 |
| `page.evaluate` | 只做 `window.scrollTo`、元素滚动、同域 `fetch` 取账号资料，无表单提交、无 DOM 注入篡改 |
| HTTP 写方法 | 全仓只有 `/json/new` 的 `PUT`（本地 CDP 开标签页）和上述两个查询 POST |
| 敏感行为护栏 | 会话过期（`status_code:8` / HTTP 403、429）立即停采；身份指纹与别名不符拒绝写入；作品按稳定 ID 关联不按标题猜；缺字段留空不补 0；未完范围写续采标记，不把走过页面计为完成 |

## 四、外发域名全集

| 域名 | 出现次数 | 性质 |
|---|---|---|
| `creator.douyin.com` | 12 | 数据源，同域本人后台 |
| `127.0.0.1` | 5 | 本机 CDP 调试端口（默认 9333），仅列标签页 / 开标签页 / 执行 JS / 关标签页 |
| `www.douyin.com` | 4 | 仅用于拼作品分享链接字符串，不发起请求 |
| `registry.npmjs.org` | 2 | `package-lock.json` 里 playwright 依赖地址 |
| `nodejs.org` | 1 | 启动器提示文字 |
| `redfox.hk` | 1 | 独立脚本，见下 |

无 webhook、无 telemetry、无 analytics、无 sentry、无第三方上报。`spawn`/`spawnSync` 调用对象都是本地进程：`claude mcp add`、Chrome/Edge/Chromium、`open`/`explorer.exe`/`xdg-open`、仓库自己的脚本。两个 `package.json` 均无 `preinstall`/`postinstall`/`install` 脚本。

`redfox.hk` 出自 `moonlit-douyin-extractor/scripts/redfox_public_metrics.py`：

| 项 | 内容 |
|---|---|
| 用途 | 用 Redfox 公开数据接口读作品公开指标（播放/点赞/评论/分享数） |
| 接口 | `POST /story/api/dyData/queryWorkList`、`POST /story/api/dyData/queryWork` |
| 计费 | [数值] 元/次，低价档按团队额度规则 |
| 默认行为 | 不加 `--run` 只打印报价（调用次数、单价、预计金额），不联网、不扣费 |
| 凭据 | `REDFOX_API_KEY` 只从环境变量读，不写文件、不打印 |
| 审批 | 单次超过 `--max-calls`（默认 20）需先报价批准再加 `--approval` |
| 登录态 | 完全不碰抖音登录态，脚本头部写明「团队 Bot 用这条路，不需要月明的抖音登录态」 |

口径待核：项目既有口径是「对标数据源已定 AE互联（红狐无 API）」，此处出现 `redfox.hk` 带可用 API 且同为对标/公开数据域，是否同一家、是否同一套额度，未核实，不并入现有选型结论。

## 五、登录态与数据流向

| 项 | `douyin-data-mcp` | `moonlit-douyin-extractor` |
|---|---|---|
| 登录态位置 | `~/.douyin-data/browser-profile`，专用 Chrome 目录，首次扫码后免登 | `~/.moonlit-creator/.auth/douyin/<别名>/`，每别名独立 profile |
| 调试端口 | 本机 9333，可用 `DOUYIN_CDP_PORT` 改；Chrome 启动参数带 `--remote-debugging-port`、独立 `--user-data-dir` | 不常驻端口，临时 Playwright profile，用完关闭 |
| 数据落盘 | `raw/YYYY-MM-DD.json` + `.sha16`，主表 CSV、总览 md、状态 md，均在 `~/.douyin-data/data/` 或仓库目录 | 按账号别名分目录 JSON，含 `_index.json`、运行记录、`_unassigned/` |
| 校验 | 页面算 sha256 前 16 位 + 字节数，本机再算一次，不一致不并表 | 采前 `--auth-probe` 复核身份指纹，不符即停写；输出目录带归属标记 |
| 上传 | 0 处 | 0 处 |
| 凭据回传 Agent | 无 | 无（`SKILL.md` 写明 Bot 不持有登录态，只读导出的 JSON） |

## 六、三处落地障碍

| 色标 | 项 | 证据 |
|---|---|---|
| 🟠 | `moonlit` 带作者本人门槛 | `extract.mjs:227` 硬校验 `MOONLIT_DOUYIN_OWNER === '1'`，否则直接退出并提示「登录态采集（B 段）只由月明本人在 Mac 上运行」；`mac-login-collector.md` 同口径 |
| 🟠 | `moonlit` 新版 SKILL 依赖私有浏览器 | `SKILL.md:35`、`mac-login-collector.md:1` 写明浏览器自动化统一走 `ego-browser` 专用空间，「不调用随包旧 Playwright 扫码、profile 或启动 Chrome 的脚本」「Ego 受阻时报具体缺口，不换浏览器」；README 里的 `npm install` + `npx playwright install chromium` 路线在 SKILL 口径下已不作为现行执行入口 |
| 🟡 | 后台内部接口无 SLA | 两个仓库都直接依赖 `/janus/douyin/creator/...`、`/aweme/v1/creator/...`；`douyin-data-mcp` 自己写了「接口变了只需要改 `collect.js`」，`moonlit` 维护了新版加密 `item_id` 的 `item_id_plain` 映射兼容 |

附带说明：`moonlit` 的 A 段（Redfox 公开指标）与 B 段（登录态私有指标）是拆开的两条路，B 段门槛不影响 A 段脚本单独使用；但 A 段是第三方付费取公开数据，与本任务「自有账号后台口径」不是同一数据源。

## 七、判定

| 色标 | 仓库 | 判定 |
|---|---|---|
| 🟢 | `douyin-data-mcp` | 源码可直接用。零第三方依赖、只读、校验严谨、README 直给 WorkBuddy MCP 配置，本机 Node 22 与 Chrome 齐备，只缺 Playwright 无关（它用 CDP 不装 Playwright）。单账号、开本机调试端口 9333 需自行留意 |
| 🟠 | `moonlit-douyin-extractor` | 源码干净但不宜直接照搬：owner 环境变量门槛 + `ego-browser` 私有依赖 + 两段式数据源。若要用于本项目，需改成通用入口或只复用其 `metrics.mjs`/`comments.mjs`/`layout.mjs` 的解析逻辑 |
| 🟡 | `redfox_public_metrics.py` | 独立脚本，默认不联网，可作为对标数据补充；与现有红狐口径是否同一家未核实 |
